#  CogniScan AI
## Explainable Multimodal AI for Three-Stage Cognitive Decline Detection

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://cogniscan-ai-anushya.streamlit.app)

## Results
| Metric | Value |
|--------|-------|
| CV F1 | 0.850 ± 0.031 |
| Test Accuracy | 78.9% |
| Micro AUC | 0.947 |
| AD F1 | 0.97 |
| Control F1 | 0.71 |
| MCI F1 | 0.68 |

## Three Novelties
1. **Three-stage classification** — Healthy / MCI / AD
2. **Dual-layer XAI** — SHAP + patient-level NL explanation
3. **Cognitive Drift Score** — Longitudinal biomarker tracking

## Dataset
- DementiaBank Pitt Corpus + Delaware Corpus
- 691 patients | Cookie Theft picture description task
